Claude Creative Uploads

A private, single-user command-line tool that uploads finished videos to two YouTube channels owned by Ionut Paulet: SidFM and Past Forward.

What it does

  • Uploads a rendered video file from the owner's computer to one of the two channels above.
  • Sets the video's title, description, tags, category, thumbnail, audience setting, AI-content disclosure and scheduled publish time.
  • Reads back the owner's own channel and video metadata to confirm the upload succeeded.

What it does not do

  • It is not distributed, sold or offered to anyone else. There is no sign-up and no website login; the only user is the channel owner.
  • It does not read, display or store any data about YouTube viewers, subscribers, commenters or other channels.
  • It does not run in the background; each upload is started by hand.

Technology

A Python script using the YouTube Data API v3 (youtube.upload and youtube.readonly scopes) through Google OAuth 2.0, running on the owner's Windows PC. Google Cloud project claude-creative-uploads.
