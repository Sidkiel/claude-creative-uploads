Privacy Policy

Claude Creative Uploads · Last updated 6 November 2026

Claude Creative Uploads ("the tool") is a private command-line application operated by Ionut Paulet ("the operator") to upload videos to the operator's own YouTube channels. This policy explains how the tool handles data.

Who uses the tool

The tool has a single user: the operator. It is not offered to the public and does not accept other users. No one else's Google account is ever connected to it.

Use of YouTube API Services

The tool uses YouTube API Services to upload videos and to read the operator's own channel and video metadata. By using the tool, the operator agrees to be bound by the YouTube Terms of Service. The Google Privacy Policy applies to Google's handling of the operator's data.

Data the tool accesses

  • Google OAuth 2.0 tokens for the operator's channels, granted by the operator.
  • Metadata of the operator's own videos and channels (titles, descriptions, tags, IDs, publishing status) returned by the YouTube API.

The tool does not access, collect, display or store any information about YouTube viewers, subscribers, comments or other channels.

Where data is stored

OAuth tokens and video metadata are stored only in local files on the operator's own computer. They are not transmitted to any third party and are not uploaded to any server other than Google's YouTube API endpoints. The tool uses no analytics, no cookies and no advertising.

Data retention and deletion

Stored tokens can be deleted at any time by removing the local token files. The operator can also revoke the tool's access from the Google Account permissions page, which invalidates the stored tokens immediately. API data retained locally is limited to video IDs and publishing metadata for the operator's own videos.

Changes

If the tool's use of data changes, this page will be updated and the date above revised.
